# فاکتوراپ (ver 23.1)

برنامه فارسی و هوشمند برای صدور فاکتور و پیش‌فاکتور، مخصوص کسب‌وکارهای کوچک و تعمیرگاه‌ها.

## امکانات اصلی
- صدور فاکتور و پیش‌فاکتور
- دو تب مجزا برای پروفایل فروشنده
- لایسنس مادام‌العمر
- پشتیبانی کامل از PWA و کارکرد آفلاین
- ذخیره‌سازی محلی در LocalStorage

## ساختار فایل‌ها
- `index.html`: برنامه اصلی
- `manifest.json`: تنظیمات PWA
- `sw.js`: سرویس ورکر برای کش آفلاین
